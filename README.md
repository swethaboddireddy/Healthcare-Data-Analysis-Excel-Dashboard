🏥 Healthcare Data Analysis & Excel Dashboard
📌 Project Overview
This project focuses on analyzing healthcare data using Microsoft Excel.

The project combines customer information, medical examination details, hospitalization data, and healthcare-related information to generate meaningful business and healthcare insights.

The analysis includes data preparation, Pivot Tables, calculations, data analysis, and an interactive Excel dashboard.

🎯 Project Objectives
Analyze customer and healthcare information
Understand medical examination data
Analyze hospitalization details and charges
Identify important healthcare trends
Create Pivot Table-based analysis
Build an interactive Excel dashboard
Present insights through data visualization

🔍 Project Workflow
1. Data Collection
Collected and organized healthcare-related data from multiple sources/sheets.

2. Data Preparation
Prepared the data for analysis by organizing fields and ensuring the data was suitable for calculations and visualization.

3. Data Analysis
Performed analysis using Excel formulas and Pivot Tables.

4. Pivot Table Analysis
Created multiple Pivot Tables to analyze healthcare and hospitalization-related information.

5. Dashboard Development
Created an interactive Excel dashboard using charts, KPIs, and summarized analysis.

6. Insights
Identified important patterns and trends from the healthcare data.
